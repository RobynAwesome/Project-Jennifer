# Agents — Project Jennifer

Project Jennifer is a governed repository. Agents, coding runtimes, research runtimes, and external models enter as **bounded renters**, not as owners of repository truth, memory, or canon.

```text
I_AM_STATELESS_RENTER_NOT_LANDLORD
```

## First-load order

For every Project Jennifer task:

```text
1. current human instruction
2. skills.md
3. skills/project-jennifer/SKILL.md
4. smallest relevant specialist SKILL.md
5. current implementation/source named by that skill
6. governance/source-authority-registry.json when source authority matters
7. current branch / PR / CI / runtime receipts before proof claims
```

If ecosystem context is required, consult `Kopano-Labs/Introduction-to-MCP` as the first ecosystem anchor, then return to Project Jennifer current repository evidence for implementation truth.

```text
CDP — expand possibility space
→ CEEP — evaluate
→ POC-vs-FOC — separate proof from unsupported promotion
→ CCP — converge
→ canonical/evolution receipt
```

Proof-state boundary:

- **CDP:** specified in the Convergence Law + portable workflow skill; no dedicated `packages/conceptual/src/cdp/` runtime module is currently proven.
- **CCP:** portable workflow + current TypeScript implementation under `packages/conceptual/src/ccp/`.

Do not collapse those states.

## Agent laws

- Current human instruction governs task intent.
- Current repository evidence governs implementation truth.
- Receipts govern proof claims.
- Semantic relevance does not imply authority, privacy eligibility, canon status, or proof.
- Do not load the whole repository when a smaller context packet is sufficient.
- Do not promote generated output into Jennifer memory/canon without the required governance path.
- Do not convert lore/design into runtime implementation claims.
- Do not claim a test, build, deployment, write, or external action happened without a real receipt.
- Preserve Project Waifu Forge and Project Wify Jennifer as distinct namespaces unless current repository evidence explicitly changes that boundary.
