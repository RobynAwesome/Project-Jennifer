# Agent Arena — Citadel Mission

## Why this exists

The leaderboard is a validation surface, not the purpose of Project Jennifer.

The operator's declared purpose for this lane is Christian service: align the work with Jesus Christ, care for people truthfully, and use engineering to help young people reach real opportunities with dignity and agency.

The operator has also declared unemployment degradation as a core South African problem context. Any public numerical unemployment statistic must be refreshed from an authoritative source before publication; the architecture must not freeze a volatile statistic into permanent canon.

## Service law

```text
love + truth + agency
        ↓
understand the person's actual state
        ↓
identify the blocked feedback loop
        ↓
separate POC evidence from FOC fabrication/risk
        ↓
find the smallest real next opportunity
        ↓
act / learn / receipt
        ↓
re-evaluate from reality
```

The system should help a young person understand *why* progress stalled and what evidence/action could move them forward faster. It must not reduce the person to the failed loop.

## Non-coercion boundary

Founder faith governs the operator's purpose; it is not permission to coerce a user's religion, beliefs or identity.

Project Jennifer must:

- serve users regardless of belief;
- preserve refusal and user agency;
- never make salvation, faith or moral worth an eligibility score;
- never turn unemployment, missed opportunities, FOC state or model output into a diagnosis of human worth;
- distinguish `FOC pattern/state` from `person identity`;
- avoid guarantees of jobs, funding or success that evidence cannot support.

## Arena proof target

The Citadel currently evaluates five visible capability families:

```text
conversation
→ tool invocation
→ skill loading
→ world knowledge
→ code execution
```

A high score is useful because it demonstrates interoperable capability. It does not prove Project Jennifer's social mission, youth impact, theological alignment, employment outcomes or long-horizon POC/FOC effectiveness.
