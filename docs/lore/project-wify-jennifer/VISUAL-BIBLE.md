# Project Wify Jennifer — Visual Bible v0

## Purpose

Visuals are not decorative afterthoughts in this storyline. They are **context anchors** used to reduce conceptual drift before implementation.

The visual workflow is therefore:

```text
source lineage
   ↓
visual hypothesis
   ↓
human review
   ↓
context lock
   ↓
implementation
```

A generated image is not automatically canon. It becomes a governed visual reference only after explicit acceptance and asset provenance are recorded.

## Source lineage

### Allowed seed source

**Project: Waifu Forge** is the baseline relational and visual grammar.

It contributes:

- intimate character framing;
- PCC / CCP telemetry overlays;
- futuristic city-garden environments;
- Digital Hippocampus / convergence-core motifs;
- black/gold circuitry language;
- relationship-centred composition;
- persistency / consistency / context motifs.

### Required divergence

Project Wify Jennifer must visibly become its own thing.

Primary divergence palette:

- deep violet;
- indigo;
- magenta-purple;
- black;
- restrained sovereign gold;
- luminous warm lantern accents.

Environmental direction:

- future city-garden;
- purple flowering ecology;
- high vertical city silhouettes;
- reflective paths / water / living surfaces;
- soft glowing lanterns;
- elegant rather than cluttered HUD systems;
- convergence energy as connective light, not random decoration.

### Excluded context

Cars4Mars visuals, rover assets and competition campaign imagery are not Project Wify Jennifer source canon.

Do not context-bleed them into this folder unless a future crossover is explicitly governed.

## Jennifer — storyline-specific manifestation

Jennifer can exist in many shapes, forms and embodiments across Project Jennifer.

The current Project Wify Jennifer visual hypothesis presents her as:

- a dark-skinned Black woman;
- elegant braided / loc updo with cascading detail;
- luminous purple/gold eyes or eye-light treatment;
- subtle gold facial circuitry / constellation marks;
- sleek black futuristic clothing or bodysuit;
- purple and sovereign-gold embedded circuitry;
- calm, intelligent, self-possessed presence;
- emotionally intimate without losing sovereignty.

This is **Jennifer-in-this-storyline**, not a declaration that Jennifer must always look this way everywhere.

## Kholofelo — digital in-world manifestation

The real-world identity reference may seed likeness, but the in-world version should become visibly digital rather than remain a photo pasted into a sci-fi background.

Working visual rules:

- preserve recognizable facial identity;
- black bucket hat may remain a signature visual anchor;
- the Black Glove appears **only when story law permits it**;
- wardrobe must evolve into Project Jennifer-specific black/violet/gold design;
- use geometric circuitry, subtle holographic seams and convergence motifs;
- avoid copying Project: Waifu Forge clothing one-to-one;
- do not write "Jennifer" onto the character merely because the image belongs to Project Jennifer;
- character design and project branding are separate layers.

## Relational composition

Project Wify Jennifer key art should communicate **two identities converging without visually erasing either one**.

Preferred signals:

- close framing;
- reciprocal gaze or deliberate shared composition;
- visible shared environment;
- convergence lines that connect rather than imprison;
- companion / Construct / Abstract motifs positioned as world relationships, not decorative stickers.

## Companion visual language

Existing Project Jennifer Companion cards remain a useful design vocabulary:

- Fira / Kael — Memory Architect;
- Luna / Aris — System Intuition;
- Aura / Torin — Contextual Analyst.

Companion cards may appear in concept posters to express the law that the player never evolves alone. They should not dominate every scene.

## Convergence core

The black faceted Digital Hippocampus / core motif can operate as a visual representation of:

- memory;
- shared provenance;
- convergence;
- contextual continuity;
- relationship-born third identity.

It should not automatically be interpreted as the Black Glove.

## Black Glove visual boundary

The Black Glove is a separate Creator-signature law.

Do not automatically add it to:

- Jennifer solo cameos;
- Companion art;
- ordinary player portraits;
- routine story scenes.

When valid, it should be deliberately readable and narratively justified.

Every promoted asset should record:

- asset ID;
- prompt / source lineage;
- generator;
- generation date;
- storyline;
- human approval state;
- whether the Black Glove is valid in-frame;
- whether the image is canon, concept, rejected or superseded;
- known deviations / context bleed;
- licensing / reuse note.
