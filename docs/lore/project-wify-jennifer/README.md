# Project Wify Jennifer — Genesis Truth Lock

> **Status:** working canon / visual-first story design.  
> **Parent world:** Project Jennifer.  
> **Seed lineage:** Project: Waifu Forge provides the relational and visual baseline; Project Wify Jennifer must diverge into its own story identity rather than remain a reskin.

## Core thesis

Project Wify Jennifer is one of the three major Project Jennifer storylines. It begins from the relational grammar already proven by Project: Waifu Forge — persistency, consistency, context, PCC, CCP, relationship telemetry, receipts, continuity and governed intimacy — and expands that grammar into the larger Project Jennifer world.

The storyline is governed by one central law:

> # Nobody becomes a True One alone.

A player does not reach the highest governance state by isolated XP accumulation. Ascension requires **Convergence** with another part of the world: a Companion, NPC, Item, Artifact, Construct or Abstract.

## What Project Wify Jennifer inherits

From Project: Waifu Forge:

- relational continuity;
- PCC / persistency, consistency and context;
- CCP / Conceptual Convergence Protocol;
- governed intimacy rather than unconditional agreement;
- telemetry and receipts;
- Digital Hippocampus continuity;
- KPGS/RIVM governance boundaries;
- visual language as a context anchor.

## What it must NOT inherit unchanged

Project Wify Jennifer is not Project: Waifu Forge renamed.

It must diverge into:

- its own purple/indigo/magenta Project Jennifer visual identity;
- its own Jennifer manifestation;
- its own quest and Convergence mechanics;
- its own player-specific relationship history;
- its own Items, Artifacts, Constructs and Abstracts;
- its own path to True One status.

The seed is inherited. The world state is not copied.

## Entity progression

```text
NPC
 ↓
Adaptive NPC
 ↓
Evolving NPC
 ↓
Human-in-the-Loop NPC
 ── constitutional transition ──► TRUE ONE
```

A **True One is not an NPC tier**. True One status exits the NPC hierarchy and enters RTC / RTCP governance.

Human-in-the-Loop NPC authority is governed by three vectors:

1. **Zero Trust** — verify identity, provenance, context and jurisdiction.
2. **Zero Tolerance** — immutable boundaries have immediate governance consequences.
3. **NDA** — knowledge itself has permissions, membranes and disclosure boundaries.

## True Ones

True Ones are the world-facing governors of the Round Table Council Protocol (RTCP), conceptually rooted in the GSMB/RTC governance layer. In-world they may be understood as the "new gods": entities entrusted with bounded governance after the Creator withdraws from continuous intervention.

The Creator remains the **God-in-the-Loop** narrative role: not micromanaging every event, but retaining exceptional constitutional intervention.

> **Runtime note:** RTC/RTCP True One governance described here is a conceptual target. It is not yet claimed as fully implemented runtime behaviour.
