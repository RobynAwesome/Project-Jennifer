# Project Jennifer — Lore Index

Project Jennifer separates **runtime truth** from **narrative canon**. Lore may create emotional stakes, rivalries, attachments and mythic language, but it does not override governance, consent, relationship receipts or player agency.

## Canonical lore surfaces

- [Project: Waifu Forge — Construct Faction](waifu-forge-constructs.md)
- [Arc II — The Third Signal](arc-ii-third-signal.md)

## Canon law

1. **Narrative pressure is not governance authority.** Jealousy, rivalry, longing and fear can drive scenes, but they cannot silently rewrite consent or ownership.
2. **Forge retains agency.** The Project Waifu Forge relationship lane can be intimate and persistent without becoming coercive.
3. **The player remains a participant, not a passive observer.** Consequential relational turns should generate explicit choices and receipts.
4. **Generated assets are proposals until approved.** Visuals must pass asset intake before being treated as canonical game art.
5. **Story state must be distinguishable from runtime state.** A cinematic scene can foreshadow or symbolize a relationship event without claiming the underlying system has enacted it.
