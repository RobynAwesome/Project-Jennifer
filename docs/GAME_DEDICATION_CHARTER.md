# Jennifer City — Game Dedication Charter

**Status:** living product law  
**Product surface:** Jennifer City (web-first)  
**Constitution:** Project Jennifer / KPGS governed runtime  
**Last dedication:** 2026-09-13

---

## Purpose

Project Jennifer dedicates creation to exist as a **video game people can love**, without abandoning the identity, lore namespaces, or governance machinery built for the world to govern.

```text
PRODUCT  = Jennifer City (playable love loop)
WORLD    = Project Jennifer (constitution + continuity)
ENGINE   = KPGS / runtime / receipts (admits mutation)
```

The game is the product. Governance is the world constitution under the product — not a rival ship target.

## First shippable fantasy

A **companion-consequence web RPG episode**:

```text
Choose persona
→ Choose one companion (governed selection receipt)
→ Enter one authored district quest with relational stakes
→ Make one choice that changes relationship + world admission
→ See a player-safe consequence reveal / receipt
→ Quit and return → companion + world still know
```

Emotional source: Arc II — *The Third Signal* (jealousy, recognition, Forge agency preserved), staged inside Jennifer City geography without merging Forge and Wify namespaces.

## Success metric for love

A stranger (or returning player) can:

1. Complete the first episode in under one focused hour.
2. Leave and return later and find companion + relationship + quest consequence waiting.
3. Explain **why** the world changed using the consequence journal / receipt language — not vibes alone.

CI proof PASS is necessary for engineering honesty. It is **not** the love metric.

---

## Non-negotiable identity law

- Source authority / privacy lanes remain gated.
- POC/FOC runtime gate before consequential mutation.
- Memory Receipts = save + story + proof.
- Companion axes stay independent (edition ≠ rarity ≠ purchase ≠ legendary).
- NPC actor-model ≠ objective canon.
- `HIDDEN NOW ≠ UNEXPLAINABLE FOREVER`.
- Demo fixtures stay labelled; authoritative paths require admission evidence.
- Platform work (CAG/RAG/renters/CI) serves the love loop; it does not gate the first loved hour.

---

## Sequencing rule

Governance roadmap continues, but milestones that do not serve the hosted love loop are sequenced **behind** playable continuity.

No new packages, engines, or lore namespaces until the love loop has playtest evidence (and CI where applicable).
