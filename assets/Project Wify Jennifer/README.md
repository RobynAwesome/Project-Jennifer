# Project Wify Jennifer — Concept Asset Manifest

This folder is the visual context-lock area for the Project Wify Jennifer storyline.

## Governance

Visuals are used to establish shared contextual understanding before code or story implementation. Generated images are **concepts until explicitly promoted**.

### Status vocabulary

- `concept` — useful visual hypothesis;
- `approved-concept` — accepted as a current context anchor, but not final production canon;
- `canon` — explicitly promoted and governed as canonical;
- `rejected` — retained only for provenance/audit;
- `superseded` — replaced by a newer accepted asset.

## Source boundary

Allowed baseline:

- Project: Waifu Forge relationship language;
- Project Jennifer Companion architecture;
- Digital Hippocampus / convergence-core motifs;
- Project Jennifer purple / violet / gold divergence.

Excluded unless explicitly governed:

- Cars4Mars campaign assets;
- rover competition visuals;
- unrelated repository imagery;
- random generated characters promoted without human approval.

## Black Glove gate

The Black Glove is not a default visual accessory. Its appearance is governed by `docs/lore/project-wify-jennifer/BLACK-GLOVE-LAW.md` and must be valid for the active major storyline/scene.

## Promotion checklist

Before promoting a visual to canon, record:

1. source references;
2. generation prompt;
3. generator/provider;
4. generation date;
5. approval state;
6. active storyline;
7. named characters/entities;
8. context-bleed audit;
9. Black Glove validity where applicable;
10. replacement/supersession relationship.
