## Law
Choose runtimes by exact capability/evidence for the current task, not permanent provider mythology.

A user-selected available renter overrides automatic ranking. Capability mismatch must be exposed rather than silently substituting another model.

## Session workflow
1. Declare session objective and authority.
2. Declare each renter's exact runtime ID, execution mode, capabilities and constraints.
3. Select required Project Jennifer skills.
4. Build NCMP/session messages with explicit source/provenance boundaries.
5. Execute bounded turns/tasks.
6. Preserve contradictions and individual renter evidence.
7. Validate merged/converged output separately from contributor agreement.
8. Return orchestration and execution receipts.

## Privacy
Before cloud egress, apply CAG lane classification, RAG source/privacy guard and renter data-egress constraints.

## Output
Return session ID, renters/runtime IDs, selected skills, routing rationale, source lanes, contributions, convergence/conflicts, validation state and receipts.
