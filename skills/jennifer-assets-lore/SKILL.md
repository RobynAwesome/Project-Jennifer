## Core law
A valid image is a source, **not automatic canon**. A lore document can be canon for story/system intent without proving the described runtime is implemented end-to-end.

Preserve namespace distinctions, especially:
- Project Waifu Forge = current/tested relational engineering, assets, constructs and receipts;
- Project Wify Jennifer = Genesis / Convergence lore and world-governance namespace.

## Intake workflow
1. Determine source owner and privacy lane.
2. Verify the actual binary/text artifact exists.
3. Normalize semantic filenames without erasing lineage.
4. Record dimensions/hash/provenance where the manifest requires it.
5. Classify source type and admission state.
6. Quarantine malformed/pointer payloads rather than presenting them as working assets.
7. Promote to canon only through the authority/validation process.

## Lore workflow
Preserve chronology, supersession, contradictions and historical naming. Do not rewrite older evidence just because current canon changed.

## Output
Return artifact/path, source class, admission state, lineage, integrity result, canon effect, affected story/runtime contract and validation receipt.
