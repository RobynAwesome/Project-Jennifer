This Vercel project is pointed at the Express API

Express cannot run as a Vercel serverless function. That is the FUNCTION_INVOCATION_FAILED crash.

To play Jennifer City on this URL:

  1. Vercel → this project → Settings → General → Root Directory → Edit
  2. Choose apps/web (Next.js). Save.
  3. Deployments → ⋯ on latest → Redeploy
  4. Open /game

Leave Output Directory empty. API hosting stays on Render, not Vercel.
